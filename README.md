# WDD 430 Portfolio

A personal portfolio application built with Next.js, React, TypeScript, and Tailwind CSS for WDD 430.

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS

## Projects

### D-TRAC
A web-based deployment monitoring system used to track merchandiser deployment and status information.

### TRADEPAD
An inventory management web application designed to help manage inventory and sales-related operations.

`SkillCard.tsx` — A reusable component that displays a technology or skill with its name and description using typed TypeScript props and Tailwind CSS.
